Method

  • Every frame is processed with MediaPipe Face Landmarker: a 478-point 3D mesh, 52 blendshapes and head pose. No frames are skipped, then all videos are resampled to one frame rate.
  • Blendshapes are mapped to FACS action units and facial muscles (for example AU12 zygomaticus major, AU4 corrugator supercilii). A camera cannot measure muscles directly; this is an estimate from skin-surface motion.
  • Evaluation uses 5-fold StratifiedGroupKFold grouped by court case. Normalization and early stopping use only the training groups.
  • No face was found in any frame of these clips, so they are excluded: trial_lie_045, trial_lie_049, trial_lie_059, trial_truth_016, trial_truth_017, trial_truth_041.
  • No names are shown; court cases appear as anonymous codes (case_01…).
